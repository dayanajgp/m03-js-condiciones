# 🧩 Proyecto: Desafío M03 - Condiciones en JavaScript

Este repositorio contiene el desarrollo del **Desafío 2 - Condiciones** del módulo de **Introducción a JavaScript**.

El objetivo fue aplicar los conceptos de **manipulación del DOM, estructuras condicionales `if`, `else if`, `else` y operadores lógicos** mediante tres ejercicios independientes.

---

## 📋 Requerimientos cumplidos

### 1. Imagen con borde interactivo

- Se muestra una única imagen.
- Al hacer clic se agrega un borde rojo de **2 píxeles**.
- Al hacer clic nuevamente se elimina el borde.
- Se utiliza manipulación del DOM y una condición `if / else`.

---

### 2. Selector de stickers

- Se incluyen **3 tipos de stickers**, cada uno con su respectivo input.
- El usuario puede ingresar la cantidad que desea de cada tipo.
- Se calcula la suma total de stickers seleccionados.
- Si la cantidad es menor o igual a **10**, se muestra la cantidad de stickers llevados.
- Si la cantidad supera los 10, se muestra el mensaje **"Llevas demasiados stickers"**.

---

### 3. Validación de password

- Se incluyen **3 elementos `select`** con opciones del 1 al 9.
- Se valida el password **911** y se muestra **"password 1 correcto"**.
- Se valida el password **714** y se muestra **"password 2 es correcto"**.
- Para cualquier otro valor se muestra **"password incorrecto"**.
- Se utiliza el operador lógico `&&` para validar las tres posiciones del password.

---

## 🛠️ Tecnologías utilizadas

- **HTML5** – estructura y contenido de la página.
- **CSS3** – estilos básicos de la interfaz.
- **JavaScript** – lógica y comportamiento de los ejercicios.
- **DOM** – selección y modificación de elementos HTML.
- **`if / else if / else`** – evaluación de condiciones.
- **Operadores de comparación** – validación de valores.
- **Operador lógico `&&`** – evaluación conjunta de condiciones.
- **Git / GitHub** – control de versiones y almacenamiento del proyecto.
